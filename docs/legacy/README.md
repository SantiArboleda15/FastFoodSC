# Documentación legacy

Estos archivos provienen de versiones anteriores y se conservaron únicamente como referencia.

- `guia_instalacion_v1.5.html`: guía de instalación de V1.5.
- `setup_v1.5.php.txt`: instalador de V1.5. Se renombró a `.txt` para evitar su ejecución accidental y porque genera un esquema distinto al de la versión actual.

No forman parte de la aplicación FastFoodSC V2.5 ni deben usarse para instalar el sistema. La instalación vigente está documentada en el `README.md` principal y en `database/fastfoodsc.sql`.
